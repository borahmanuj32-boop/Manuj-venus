# AxomBook - অসমৰ নিজৰ Facebook 📘

> Made with ❤️ in Assam by Manuj Borah & Venus Art Gallery

AxomBook হৈছে অসমীয়া মানুহৰ বাবে বনোৱা Facebook নিচিনা Social Media Platform।

**Live Website:** https://borah11.github.io/Manuj-venus/

### ✨ Features

- 🔐 **Real Login System** - Gmail / Password
- 📝 **Real Post** - Text, Photo, Video
- ❤️ **Like / Comment / Share** - 7 Reactions
- 👥 **Friend System** - Friend Request, Follow
- 💬 **Real Chat** - Messenger Style
- 🔔 **Notification**
- 📖 **Story / Reels**
- 🌙 **Dark Mode**

### 🚀 Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Firebase (Authentication + Firestore)
- Hosting: GitHub Pages
- Owner: Manuj Borah

### 📂 How to Run

1. Clone the repo
2. Add your Firebase Config in `firebase.js`
3. Enable Email/Password in Firebase Console
4. Deploy!
